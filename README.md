# Personal Website

A lightweight, responsive personal website using only HTML, CSS and JavaScript.

## Free deployment

This site is designed for GitHub Pages.

1. Create a GitHub repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. In **Settings → Pages**, select **Deploy from a branch** and choose the `main` branch.
4. Open `https://YOUR-GITHUB-USERNAME.github.io`.

GitHub Pages is available with GitHub Free for public repositories.

## Customize

Replace:
- `Your Name`
- professional title
- About section
- expertise
- projects
- email
- LinkedIn
- GitHub
- initials in the avatar

The site has no paid libraries, database, backend, tracking code or proprietary framework.
